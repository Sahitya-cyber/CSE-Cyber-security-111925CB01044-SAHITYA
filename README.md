Factorial Program in Python 🐍

📌 About the Project

This project contains a simple Python program to calculate the factorial of a given number.

The program accepts a number from the user and calculates its factorial using a "for" loop.

📖 What is Factorial?

The factorial of a non-negative integer "n" is the product of all positive integers from "1" to "n".

For example:

5! = 5 × 4 × 3 × 2 × 1
   = 120



▶️ Sample Input

Enter a number: 5

✅ Sample Output

Factorial of 5 is 120

🧠 Concepts Used

- Python variables
- User input
- Type conversion using "int()"
- "for" loop
- Arithmetic operators
- "print()" function

⏱️ Complexity

- Time Complexity: "O(n)"
- Space Complexity: "O(1)"

🚀 How to Run

1. Install Python on your system.
2. Clone or download this repository.
3. Open the terminal in the project folder.
4. Run the program:

python factorial.py

5. Enter a number when prompted.
